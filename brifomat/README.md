# Брифомат

Одностраничный генератор случайных брифов для дизайнера. Задача в каждом брифе одна: придумать оригинальный брендинг для Nachbild, курса по аналоговой фотографии. Курс делает компания из Вены; её название выбирает барабан, поэтому варианты названий немецкие.

Четыре барабана, как в слот-машине: «Ниша», «Настроение», «Название компании» и «Цвета». Барабаны оформлены как плёнка 35 мм, а выбранный кадр обводится красным восковым карандашом, как на контактном листе.

- **Крутить** запускает все барабаны сразу, останавливаются они по очереди.
- Клик по барабану крутит только его.
- С клавиатуры: пробел крутит все барабаны, клавиши 1–4 крутят отдельный барабан.
- В барабане «Цвета» показаны двухцветная плашка и название палитры.
- Под барабанами собирается текст брифа. Кнопка «Скопировать бриф» копирует его целиком, клик по цвету копирует его HEX-код.
- Звук щелчков выключается кнопкой «Звук», выбор запоминается в браузере.

## Как открыть

Откройте `index.html` в браузере. Сборка и сервер не нужны. Шрифты (Sofia Sans, Sofia Sans Extra Condensed, IBM Plex Mono, Caveat) подгружаются из Google Fonts; без интернета страница работает на системных шрифтах.

## Как поменять варианты

Варианты лежат в массиве `REELS` в начале скрипта в `index.html`: ниши, настроения, названия и палитры (название и два HEX-цвета). Список «Что показать» — в константе `TODO` рядом.
