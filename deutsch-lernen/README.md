# 🇩🇪 Deutsch A2 — Prüfungs-Bootcamp

Eine super interaktive Lern-Website für deine **Deutsch-A2-Prüfung** — gebaut für Lernen mit **ADHS**: kurze Sprints, sofortiges Feedback, XP & Belohnungen, Fokus-Timer.

## 🚀 So startest du (2 Sekunden)

**Einfach `index.html` im Browser öffnen.** Fertig. Kein Internet, keine Installation nötig — funktioniert auch auf dem Handy.

> Tipp: Funktioniert direkt per Doppelklick. Für die beste 🔊-Sprachausgabe (Chrome/Edge/Safari) kannst du auch einen Mini-Server starten:
> ```bash
> cd deutsch-lernen
> python3 -m http.server 8000   # dann http://localhost:8000 öffnen
> ```

## 📚 Was drin ist (genau dein Prüfungsstoff)

**Modul 1** · **Modul 2** · **Modul 3** + Bonus — insgesamt **10 Lektionen, 64 Übungen, 112 Vokabeln, 18 Prüfungsfragen**.

| Lektion | Thema | Grammatik |
|--------|-------|-----------|
| L1 | Kindheit & Vergangenheit | Perfekt (haben/sein, -ieren) + temporale Adjektive |
| L2 | Berufe & Stress am Arbeitsplatz | weil-Sätze |
| L3 | Umzug · Hamburg & Wien | Possessiv-Artikel (Nom/Akk/Dat) |
| L4 | Vor- & Nachteile · Vergleichen | deshalb-/denn-Sätze + Komparativ |
| L5 | Termine vereinbaren | temporale Präpositionen (um/am/im, seit, von–bis) |
| L6 | Kultur & erstes Date | könnte/sollte (Konjunktiv II) |
| L7 | Meinung & Argumente | dass-Sätze |
| L8 | Sportarten | wenn-Sätze |
| L9 | Wohnung einrichten | Wechselpräpositionen + legen/stellen/hängen |
| L12 | Höflich fragen | indirekte Fragen (ob, wie lange …) |

## ✨ Features

- **⚡ Schnellkurs** — geführter 2-Stunden-Plan für morgen (5 Sprints mit Pausen)
- **🍅 Fokus-Timer** (Pomodoro) — oben rechts, hält dich im Tunnel
- **✍️ 4 Übungstypen** — Multiple Choice, Lücken, Satz bauen, Zuordnen — mit **sofortigem Feedback**
- **🃏 Karteikarten** mit **🔊 deutscher Sprachausgabe**
- **🎯 Prüfungssimulation** mit Ergebnis in %
- **📅 2-Wochen-Plan** für entspanntes Lernen
- **🏅 XP, Level, Streak & Konfetti** — Motivation für dein Gehirn
- **🌙 Dunkelmodus** & **🧘 Ruhe-Modus** (weniger Animationen)
- Fortschritt wird **automatisch gespeichert**

## 🧠 ADHS-Tipps (eingebaut)

1. **Ein Sprint = ein kleines Ziel.** Timer an, Handy weg, los.
2. **Übungen machen, nicht nur lesen** — beim Tun bleibt es hängen.
3. **Pausen sind Teil des Plans**, kein Versagen.
4. **Konsistenz schlägt Kraft** — lieber täglich 25 Min als einmal 3 Std.

Viel Erfolg bei der Prüfung — du schaffst das! 💪
