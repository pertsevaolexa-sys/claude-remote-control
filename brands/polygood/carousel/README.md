# Polygood® Wall Tiles — Instagram carousel

8 slides, 1080 × 1350 (Instagram 4:5).

**Canvas:** https://claude.ai/code/artifact/29745673-d72e-4b0b-9d1b-cbf08dc0a9a4
(view, edit and export PNG/PDF per slide from the Export menu)

## Files

| File | What it is |
|---|---|
| `build.py` | Source of truth. Holds the brand tokens, the terrazzo generator and all eight slides' markup. |
| `*.dc.html` | Generated artboards, one per slide. Do not hand-edit — they are overwritten by the build. |
| `terrazzo.svg` | Generated seamless terrazzo tile, shared by every slide. |
| `canvas.json` | Canvas layout (two rows of four, reading order). |
| `fonts/` | Latin-subset woff2 for Archivo and IBM Plex Mono, embedded so PNG exports use the real faces. |
| `COPY.md` | On-slide copy, caption, hashtags, per-slide alt text. |
| `SOURCES.md` | Where every product claim came from. |

The seeded canvas file itself (`polygood-wall-tiles-carousel.html`, ~2.6 MB) is
gitignored — it is a build output of the design canvas, regenerated by seeding.

## Rebuild

```bash
python3 build.py
```

## Applying the real brand book

Colour and type are currently a documented interpretation, not the Figma brand
book (see the status note at the top of `../brand-dna.md`). To swap in the real
values:

1. Edit the `TOKENS` block and the `CHIPS` list near the top of `build.py`.
   Everything brand-governed lives there — nothing else needs touching.
2. Replace the fonts in `fonts/` if the brand book specifies different faces,
   and update the `@font-face` names in `CSS`.
3. Replace the `Polygood®` wordmark, currently set as live text, with the real
   logo asset.
4. `python3 build.py`, then re-seed and republish the canvas to the same URL.
