# SEO for the four case studies

Every SEO field for the four cases: the page fields for the SEO box (Yoast, Rank Math or similar) and the Media Library fields for each photo. None of this goes into the page HTML. The SEO plugin writes the meta tags from these fields.

**How the keyphrases were chosen.**
- **Focus keyphrase:** the most specific phrase each page can own, so the four cases don't compete with each other or with the pattern and application pages.
- **Related keyphrases:** the broader search terms. You can enter them in Yoast Premium or Rank Math. Free Yoast has only the focus keyphrase field.

**Warnings to expect.**
- The plugin will warn that each text is under 300 words. That's fine: the live case pages are shorter still.
- It may also flag the keyphrase in the slug and in the first paragraph. The slugs stay as short names to match the live cases.

**Fields for all four cases.**
- **Canonical URL and robots:** leave at the defaults.
- **Schema tab:** leave at the defaults.
- **X (Twitter) fields:** leave empty. They fall back to the social title, description and image.
- **Translated versions:** each language version needs its own SEO fields.

## Media Library fields

- **Alt text:** read aloud by screen readers and used by image search. Fill it in for every photo.
- **Title:** only shows in the Media Library, but it replaces the file name there.
- **Caption:** shows under the photo if the theme displays captions. It carries the photo credit.
- **Description:** can stay empty.
